# Universal Vibe Coding Bootstrap

Use this repository as the starting point for every new AI-assisted application.

Included:
- `AGENTS.md` — universal agent safety and workflow rules
- `skills/progressive-distillation/SKILL.md` — reusable experiential-learning and self-correction system

## New-project workflow

1. Create a new repo from this bootstrap/template.
2. Keep `AGENTS.md` at the repository root.
3. Keep the `skills/` directory intact.
4. Add project-specific rules underneath the universal rules.
5. Add stack-specific architecture, data model, testing, and security docs as the project evolves.

## Critical rule
Project-specific instructions may be stricter than the universal bootstrap but should not silently weaken its safety protections.
